# 夜班奶茶铺

竖屏奶茶铺，做法借鉴沙威玛：配方是固定的一份清单，加料不限顺序，做好后拖给任何一位要这杯的客人。蟑螂会舔料、爬杯子。没有最终关，天数可以一直增加。

## 怎么做一杯

客人头顶写着饮品名和标准做法，例如「西瓜、椰果、加水、摇2次」。台上一开始就有空杯，不用先点客人。

- 按住杯子加水，松手会停，再按继续，加满为止。
- 小料点一下加一份，先加哪种都行。同一种不能加两次。
- 摇匀按客人要求的次数。摇多了、少了都不是这杯。
- 水、料、摇的次数和某位客人的清单完全一致，才能封杯。封好的杯子最多在台上放三杯。
- 把杯子拖给任何一位清单一致的客人，排在第三位也可以。拖给要别的饮品的人，算差评。

点客人只会再看一遍他的清单，不会把杯子绑到他身上。

柜台左边放着一只拖鞋，点那只鞋把它拿起来，再点蟑螂或报假单号的人。打完它会回到原位。拖鞋下面是垃圾桶，点一下倒掉正在做的这杯；已经封好的杯子也可以拖进去扔掉。

右上角「测试」可以跳到指定天数。跳关按那一天的正常预算开，不受上一天评分影响。

## 一天怎么生成

每一天先用天数算出预算，再抽一条班次规则。规则之间不叠加。

订单名字、配方、假单号和断货的碗用天数做种子，同一天重开，这些内容相同。小偷会不会出现还看你什么时候封杯，所以后半段会跟着操作走。

前一天结算时评分低于 3.0，下一天只出普通夜班或熟客夜，蟑螂再减 1。连续两天结算为「紧」，并且已经开到第 4 天，下一天必是熟客夜。

### 预算

做成率不写进游戏，只在估算盈亏时按 58% 看。

| 项目 | 公式 | 边界 |
| --- | --- | --- |
| 班次时长 | `100 + 8 × 天数` 秒 | 100–240 秒。暴雨客流再 ×0.8 |
| 来单间隔 | `10.5 - 0.35 × 天数` 秒 | 最快 4.2 秒。赶单再 ×0.75 |
| 同时在场 | `2 + 天数 / 3` | 2–5 人。暴雨客流 +1，仍不超过 5 |
| 每杯配料 | 第 1 天 1 种，之后 `1 + (天数 - 1) / 4` | 最多 4 种。挑嘴 +1，仍不超过 4 |
| 摇匀 | 第 1 天 0 或 1 次，第 2 天 0–2 次，之后 1–3 次 | 必须和清单一致 |
| 杯价 | `12 + 4 × 配料种数 + 2 × 摇匀次数 + 每 5 天 2 元` | 挑嘴再 ×1.25，四舍五入 |
| 客人耐心 | `46 - 1.1 × 天数` 秒 | 最少 18 秒。赶单 ×1.15，熟客夜 ×1.3 |
| 假单号概率 | `0.25 + 0.04 × 天数` | 最高 70%。熟客夜为 0 |
| 小偷停留 | `12 - 0.4 × 天数` 秒 | 最少 6 秒 |
| 蟑螂数量 | `1 + 天数 / 4` | 1–4 只。虫害 +1，仍不超过 4 |
| 蟑螂再出现 | `9 - 0.25 × 天数` 秒 | 最快 4 秒 |
| 租金 | `30 + 14 × 天数^0.85` | 四舍五入。熟客夜 ×0.85 |

时长和密度到顶以后，压力改由租金、虫害和库存承担。

### 班次规则

每天只抽一条。权重和改动如下。

| 规则 | 解锁 | 权重 | 改动 |
| --- | --- | --- | --- |
| 普通夜班 | 第 1 天 | 10 | 不改预算 |
| 赶单 | 第 2 天 | 4 | 来单更快，客人更有耐心 |
| 挑嘴 | 第 3 天 | 3 | 多一种料，杯价提高 |
| 虫害 | 第 3 天 | 4 | 多一只蟑螂，碗更容易脏 |
| 熟客夜 | 第 4 天 | 2 | 没有小偷，耐心更长，租金打 85 折 |
| 稽查 | 第 4 天 | 3 | 小偷伪装提高一级，罚款 ×1.5 |
| 暴雨客流 | 第 5 天 | 2 | 班次更短，同时多留一位客人 |
| 断货 | 第 6 天 | 3 | 随机两只碗的库存减半 |

## 蟑螂、洗涤、补货

蟑螂从柜台边缘慢慢爬向杯子和料碗。第 1、2 天速度大约是后面的一半，出生点离料碗更远。

| 天数 | 发生的事 | 怎么处理 |
| --- | --- | --- |
| 1–2 | 舔料碗会叠上口水。用这只碗加料，杯子带蟑螂味，交餐少 2 元。在杯子上站满 4 秒，这杯倒掉 | 点那只碗把口水擦掉。拿起拖鞋再拍 |
| 3–5 | 污渍叠到 3 层就锁碗。垃圾桶旁边出现一只水槽 | 点水槽，或点写着「要洗」的碗。洗一只要 1.8 秒 |
| 6 天起 | 每叠一层污渍，再扣 1 份库存。见底不能舀 | 点「补货」那只碗。一份 `8 + 天数` 元，要 1.5 秒 |
| 8 天起 | 蟑螂在杯子上停留约 0.4 秒，杯子变脏。水槽旁边出现涮杯池 | 封杯前点涮杯池，1.2 秒。不涮就封，罚款并差评 |

库存从第 6 天才显示，碗上写「余 N」。

小偷的样子随天数收掉：第 1 天有红圈，第 2 天只剩深色衣服和红单号，第 3 天只剩皱眉，第 4 天起外形和真客人一样，只能对单号。稽查会把伪装再提高一级，最高到「只看单号」。拿着拖鞋点他才能打走。

## 日结

打烊时先扣租金。

净利 = 营收（含打走小偷的 15 元）− 罚款 − 被偷 − 补货 − 租金。

| 结果 | 条件 |
| --- | --- |
| 顺 | 净利不少于租金，并且评分不低于 4.0 |
| 平 | 净利至少到租金的七成，并且评分不低于 3.0，但还没到「顺」 |
| 紧 | 净利不到租金的七成，或评分低于 3.0 |

评分是累计的：从 5.0 起，差评占比越高掉得越多，最低 0。超时罚款 10，给错人或没涮就封罚款 20。稽查那天这两笔都 ×1.5。

没有最终关。下一天用这一天的评分和「紧」的连续次数决定班次。
